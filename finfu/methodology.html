Methodology & coverage

Pipeline. (1) Enumerate last-5-yr uploads via yt-dlp --flat-playlist (no API key). (2) Fetch transcripts: youtube-transcript-api → yt-dlp auto-subs → Jina Reader fallback. (3) LLM structured extraction of forward calls (ticker, action, target, horizon, conviction, quote). (4) Adversarial second-pass verification — commentary and pure historical disclosure are dropped; majority-refute discards the call. (5) Backtest each surviving call against this repo's price/benchmark data layer (yfinance; SPY for US, ^NSEI for India); alpha = direction-adjusted, benchmark-relative return over the stated (or default 6-month) horizon. (6) Aggregate per creator.
Honesty on gaps. Only forward, dated calls are scored — pure "here's what I hold" disclosure is excluded. X/Twitter, Telegram, TikTok have no free no-key historical path, so X-primary creators with no YouTube uploads are listed below as skipped rather than silently dropped. Transcript coverage overall: 100.0% of in-window videos yielded free text (1882/1882).
